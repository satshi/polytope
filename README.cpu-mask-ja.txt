今回の変更: 可視判定だけを元のCPU倍精度計算に戻しました

- 色別の静的バッチとGPU頂点射影は維持
- 元の判定式・演算順序・厳密な >0 を使用。epsilonは加えていません
- 可視/不可視の1byteマスクだけをGPUへ送信。値が同じなら転送要求を省略
- GPUは胞IDから対応texelを読むだけ。法線のFloat32判定を除去
- c120sは4メッシュのまま、マスクは100×99で9,900bytes
- 詳細はBATCHING.md、比較計測は同梱benchmark/を参照
